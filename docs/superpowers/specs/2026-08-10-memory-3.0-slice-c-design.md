# Strata Memory 3.0 — Slice C Design (Engineering Maturity)

**Status:** approved for implementation  
**Date:** 2026-08-10  
**Source:** `memory3.0.pages` optimization brief (scope-recall / Mem0 / Graphiti patterns)

## Goal

Deepen 2.0 without architecture rewrite:

1. **Write governance** — typed TTL/status defaults, near-dup → supersede version chain, provenance
2. **Recall quality** — multi-signal rerank + score_breakdown + session filter
3. **Ops** — doctor metrics + `strata_hygiene`

## Non-goals (this slice)

Web dashboard, kill-switch UI, full knowledge graph, external gold eval harness.

## Data model (schema v3)

Additive columns on `memories` (ALTER-safe):

| Column | Purpose |
|--------|---------|
| `supersedes_id` | Prior memory this row replaces |
| `superseded_by` | Successor id (set when archived by supersede) |
| `authority` | agent \| user \| system |
| `sensitivity` | normal \| sensitive \| internal |
| `entity` | Optional entity key for related recall |
| `validator_kind` | Always `quality_kernel` (deterministic) |
| `ttl_days` | Typed default (null = permanent) |
| `provenance` | JSON: source session, journal_id, extractor |

## Write path

```
commit_memory
  → QualityKernel (types + decision_record, forced TTL/status/validator_kind)
  → exact hash dedup → touch
  → FTS near-dup (same type, token overlap ≥ threshold) → supersede old
  → insert with provenance
  → optional embed
```

## Recall path

```
RRF(vector, FTS)
  → load rows
  → filter: active, not other-session scratch, optional session boost
  → multi_signal = recency × relevance_rrf × importance × (1+usage_boost) × freshness
  → return score + score_breakdown
```

## Ops

- `strata_doctor`: schema version, hash dups, secret residual sample, api key
- `strata_hygiene`: dry-run archive expired, report dups/secrets; optional apply archive
