STRATA-MEMORY Logo Extension V2

All SVGs contain vector shapes, including outlined Latin wordmark; no external fonts needed.
- wordmark_*_transparent: standalone `strata-memory` wordmark, transparent background
- lockup_*_transparent: horizontal symbol + wordmark, transparent background
- icon_*_transparent: original icon with green recall dot, transparent background
- icon_*_minimal: no-dot icon with solid rounded square background
- icon_*_minimal_transparent: no-dot icon with transparent background
- favicon_minimal_*: no-dot favicon sizes and .ico
- preview_v2.png: light / dark horizontal applications and gray card overlay checks
Light and dark SVGs have different fills optimized for backgrounds. PNGs are raster versions of those vector files.
Original package files are retained in the v2 zip under original/.
